วิธีการตั้งค่า Web App URL เพื่อบันทึกข้อมูลลง Google Sheet

ขั้นตอนการเอา Web App URL มาใส่ (ทำเพียงครั้งเดียว):
  1. เปิดไฟล์ Google Sheet ทะเบียนคุมงานของคุณ
  2. ไปที่เมนูด้านบน ส่วนขยาย (Extensions) → Apps Script
  3. วางซอร์สโค้ดจากไฟล์ apps-script/Code.gs ในโปรเจกต์นี้
  4. กดปุ่มสีส้ม ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้ใหม่ (New deployment)
  5. เลือกประเภท ⚙️ เว็บแอป (Web app) กำหนดสิทธิ์ผู้เข้าถึงเป็น "ทุกคน" (Anyone) *(สำคัญมาก!)*
  6. กด Deploy แล้วคัดลอก URL ที่ได้ (ลงท้ายด้วย /exec) มาวางในช่องด้านล่างนี้
เชื่อมต่อ Web App เรียบร้อยแล้ว! ทุกการกรอกและแก้ไขจะบันทึกลง Google Sheet จริงทันที
