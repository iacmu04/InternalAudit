# ระบบติดตามงานตรวจสอบและขอขยายระยะเวลาออนไลน์ (Internal Audit Tracking & Extension System)

ระบบบริหารจัดการและติดตามสถานะงานตรวจสอบภายใน และระบบขอขยายระยะเวลาการตรวจสอบออนไลน์ Real-time ผ่าน Google Sheets พัฒนาขึ้นสำหรับสำนักงานการตรวจสอบภายใน (รองรับผู้ใช้งานได้ถึง 20 คน)

---

## 🌟 ฟีเจอร์หลักของระบบ

### 1. ระบบติดตามงานตรวจสอบ (Internal Audit Tracking System)
- **แดชบอร์ดสรุปผลแบบเรียลไทม์**: แสดงอัตราร้อยละจำนวนส่วนงานที่ดำเนินการเสร็จสิ้นสมบูรณ์ (คอลัมน์ S) จากส่วนงานทั้งหมด
- **วิเคราะห์สถานะ 4 ขั้นตอนหลัก (พร้อมสีเฉพาะตามระบุ)**:
  - 🔵 **1.1 ก่อนเข้าตรวจ (`#5167D7`)**: มอบหมายงาน (D), แจ้งเข้าตรวจ (E), อนุมัติแผน (F)
  - 🟣 **1.2 ระหว่างการตรวจสอบ (`#B086DF`)**: เปิดตรวจ/เริ่มตรวจสอบ (G), สิ้นสุดตรวจสอบ (H), ประชุมปิดตรวจ (J)
  - 🟪 **1.3 รายงานผลการตรวจสอบ (`#E2DCF5`)**: เสนออธิการบดี (K), แจ้งหน่วยรับตรวจ (M), เสนอ คตส. (N)
  - 🌿 **1.4 ชี้แจงผลการดำเนินงาน (`#839B77`)**: หน่วยรับตรวจชี้แจง (Q), เสนออธิการบดี (R), เสร็จสมบูรณ์ (S)
- **การคำนวณวันตรวจจริงอัตโนมัติ (ข้อ 2.3)**:
  - คำนวณวันตั้งแต่วันเริ่มตรวจ (G) ถึงวันสิ้นสุด (H)
  - หักวันเสาร์-อาทิตย์
  - หักวันหยุดนักขัตฤกษ์ (จากชีท `Thai_Holidays`)
  - หักวันที่ไม่ได้เข้าตรวจจริง (จากชีท `Non_Audit_Days` กรองตามส่วนงานตรงกัน)
- **การติดตามกรอบเวลา 60 วันเสนอ คตส. (ข้อ 2.5 & 2.6)**:
  - แสดงจำนวนวันที่ใช้เสนอ คตส. (N - J)
  - แถบสีแดงเมื่อเกิน 60 วัน
  - แถบเตือนภัยสีแดงกะพริบเมื่อใกล้ครบกำหนด (&ge; 50 วัน)
- **สรุปประสิทธิภาพรายทีม (ข้อ 3 & 4)**: แสดงระยะเวลาเฉลี่ยที่ใช้ในการตรวจสอบจริง และระยะเวลาเฉลี่ยที่ใช้ในการเสนอ คตส. แยกรายทีม

### 2. ระบบขอขยายระยะเวลาการตรวจสอบ (Extension Request System)
- **3 ปุ่มแอคชันหลักบน Dashboard**:
  - ➕ **เพิ่มข้อมูลการตรวจสอบ**: เปิดฟอร์มกรอก/เพิ่ม registry งานตรวจสอบ
  - ⏳ **ขอขยายระยะเวลาการตรวจสอบ**: เปิดฟอร์มยื่นคำขอขยายเวลา
  - ✏️ **แก้ไขข้อมูล**: เปิดหน้าจัดการและแก้ไขข้อมูลแถวที่มีอยู่เดิม
- **การ์ดสรุปจำนวนรวม (สำหรับทุกบทบาท)**:
  - แสดงจำนวนรายการ **รอพิจารณา (ค้างอยู่ที่หัวหน้างาน)**
  - แสดงจำนวนรายการ **รออนุมัติ (ค้างอยู่ที่ผู้อำนวยการ)**
  - User ทั่วไปจะเห็นตัวเลขสรุปจำนวนรวมโดยไม่เห็นรายละเอียดของผู้ใช้อื่น
- **Workflow อนุมัติและตีกลับ**:
  - `User` ยื่นคำขอ -> `Leader` พิจารณา -> `Dean` (ผอ.) อนุมัติ
  - หาก `Leader` ตีกลับพร้อมเหตุผล -> `User` สามารถแก้ไขเหตุผลแล้วส่งใหม่ หรือกดขอยกเลิกคำขอได้

## 📁 โครงสร้างชีทใน Google Sheet (6 ชีท)

1. `Main_Audit`: ทะเบียนคุมงานตรวจสอบหลัก (คอลัมน์ A ถึง S)
2. `Delay`: ทะเบียนคำขอขยายเวลา (Timestamp, Requestor, Email, Department, Start Date, End Date, Reason, Supervisor Name, Status, Supervisor Action Date, Director Action Date, Remarks)
3. `Users`: รายชื่อสิทธิ์ผู้ใช้ (Email, Name, Role, Team, Authorize)
4. `Master_Lists`: ข้อมูลตัวเลือก Dropdown (ส่วนงาน, ทีม, ครั้งที่ประชุม คตส. - รองรับการเพิ่มส่วนงานใหม่จากหน้าฟอร์ม)
5. `Thai_Holidays`: วันหยุดนักขัตฤกษ์ (วันที่, รายละเอียดวันหยุด)
6. `Non_Audit_Days`: วันที่ไม่ได้เข้าตรวจจริง (วันที่, ประเภท, ส่วนงาน, สาเหตุ/หมายเหตุ)

## 🚀 วิธีการเชื่อมต่อ Google Sheet กับ Google Apps Script (Backend)

1. เปิดไฟล์ Google Sheet: [ทะเบียนคุมงานตรวจสอบ](https://docs.google.com/spreadsheets/d/1DsRayuheR7DUA-Zd4S8tCffAsl5C_o4s078HcJc0rKw/edit?usp=sharing)
2. ไปที่เมนู **ส่วนขยาย (Extensions)** &rarr; **Apps Script**
3. คัดลอกซอร์สโค้ดจากไฟล์ `apps-script/Code.gs` ไปวางในโปรเจกต์ Apps Script
4. กดปุ่ม **ทำให้ใช้งานได้ (Deploy)** &rarr; **การทำให้ใช้งานได้ใหม่ (New deployment)**
5. เลือกประเภท: **เว็บแอป (Web app)**
   - คำอธิบาย: Internal Audit API
   - ดำเนินการในฐานะ: **ฉัน (Me)**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)**
6. กด **ทำให้ใช้งานได้ (Deploy)** และคัดลอก **URL เว็บแอป (Web App URL)**
7. นำ Web App URL ไปใส่ในไฟล์ `js/api.js` ตรงตัวแปร:
   ```javascript
   let APPS_SCRIPT_URL = "https://script.google.com/macros/s/.../exec";
   ```

## 💻 การ Deploy ขึ้น GitHub Pages (Frontend)

1. พุชโค้ดทั้งหมดในโฟลเดอร์นี้ขึ้น Repository บน GitHub
2. ไปที่ **Settings** ของ Repository บน GitHub
3. ไปที่หัวข้อ **Pages** (ทางซ้ายมือ)
4. เลือก Build and deployment: **Deploy from a branch** (Branch: `main` / `master`, Folder: `/ (root)`)
5. กด **Save** ระบบจะให้ URL สำหรับเข้าใช้งานระบบผ่าน Browser ได้ทันทีฟรี!
